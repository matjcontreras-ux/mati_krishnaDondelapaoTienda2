#Dondelapao Tienda - E-Commerce Next.js

Proyecto académico de comercio electrónico para la venta y gestión de productos de limpieza, desinfectantes e higiene. Desarrollado con una arquitectura moderna utilizando *Next.js (App Router)* y *TypeScript*, asegurando una experiencia de usuario rápida e intuitiva.

Desarrollado por: *Matías Contreras* y *Krishna Contreras*.

---

##Novedades y Funcionalidades Completas

El proyecto cuenta con un sistema completo de navegación y gestión, incluyendo las últimas actualizaciones:

- *Catálogo & Categorías*: Visualización dinámica de productos organizados por categoría.
- *Flujo de Compra Completo*: Carrito de compras, cálculo de totales, formulario de Checkout y simulación de pasarela de pago (Pantallas de Éxito / Error).
- *Panel Administrador (CRUD)*: Sistema de gestión para crear, leer, actualizar y eliminar productos del catálogo en tiempo real.
- *Autenticación (NUEVO)*: Vistas de Iniciar Sesión (/login) y Crear Cuenta (/registro).
- *Nuevas Secciones Informativas*: 
  - *Ofertas (/ofertas)*: Productos destacados y con descuento.
  - *Nosotros (/nosotros)*: Misión, visión y pilares de la tienda.
  - *Blog (/blog)*: Artículos y consejos de limpieza.
  - *Contacto (/contacto)*: Formulario de atención al cliente e información de contacto del equipo de desarrollo.
- *Persistencia de Datos*: Manejo de inventario, sesiones y carrito utilizando localStorage.
- *Testing Automatizado*: Suite de 10 pruebas unitarias con Jest verificando la lógica de negocio al 100%.

---

##Tecnologías Utilizadas

- *Framework*: Next.js (React)
- *Lenguaje*: TypeScript / JavaScript
- *Estilos / UI*: Bootstrap 5 + Bootstrap Icons
- *Capa de Datos*: LocalStorage (In-Memory persistente)
- *Testing*: Jest + JSDOM
- *Control de Versiones*: Git & GitHub
